## 🚀 GETTING STARTED

### Quick Start (5 minutes):
```bash
# 1. Clone the repository
git clone https://github.com/Seevaranjinee/calorie-tracker-app.git
cd calorie-tracker-app

# 2. Install dependencies
npm install

# 3. Update Supabase credentials
# Edit src/lib/supabase.js with your Supabase URL and Key

# 4. Run locally
npm run dev

# 5. Build for production
npm run build
```

### GitHub Pages Deployment:
- App auto-deploys from the `dist/` folder
- Visit: https://seevaranjinee.github.io/calorie-tracker-app/
